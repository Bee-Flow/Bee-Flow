# exists in server/i18n/defaults/en/ on the base branch is missing on the pull
# request — that is what a merge in which "the second wins" looks like. A key
# you delete deliberately goes here, one per line, so the guard knows the
# removal is intended. `#` starts a comment; blank lines are ignored.
#
# An entry only matters while the base branch still has the key. Once the
# removal is merged, the line can go in any later cleanup.
