## What holds

- **"Gone" vs "error" cannot be confused.** `configStore.getConfig` returns `null` only when the
  row is absent (no swallowed errors; a DB failure rejects), and `getProject` returns `null` only
  when the stored value is not a plain object. Every other outcome of a read throws, and
  `checkStoredLiveSite` keeps the pointer and logs on a throw. The pointer is now written to null
  only on a real "no such project" answer.
- No write on the error path, so a blip no longer propagates to every replica via the config
  invalidation channel.
- The log line carries only the error message, no site content.
- Tests cover exists / gone / transient error with injected deps.
