# Endpoint reference

Every route the server mounts, 1845 in all, read from the running app rather than written by hand. 1027 of them declare a request schema (body, query or path parameters), shown below as fields; the other 818 say "No request schema". The same data as an OpenAPI 3.1 document: [openapi.json](pathname:///openapi.json).

## How to read it

- **Access** lists what the middleware chain demands: a signed-in user, a permission, a licence feature, a capability, or a named middleware such as `requireAdmin`. A handler can check more inside its body. A route that says "no gate in the middleware chain" is decided by its handler: it checks the session itself, or it is public (login, health, a webhook that verifies a signature).
- Browsers authenticate with a session cookie; scripts and the Nextcloud connector send a signed bearer JWT. See [Authentication](./auth.md).
- "No request schema" means the route does not use `validate(...)`; it may still read a body or query by hand.
- Responses are not described: the code does not declare them. Errors use the [common JSON format](./index.md#error-format).
- The opt-in MCP endpoints under `/mcp` are listed too; each is mounted only when its flag is set on the server.
